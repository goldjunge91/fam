# Englische Screenshots ausstehend

Die App hat aktuell keine i18n/Übersetzungsschicht (kein `en.json`, keine
`expo-localization`-Nutzung) — die komplette UI ist fest auf Deutsch codiert.
Englische Screenshots würden also nur dieselbe deutsche Oberfläche zeigen,
keine echte Übersetzung.

Deshalb wurden hier bewusst keine Screenshots erzeugt. Sobald die App eine
englische Lokalisierung hat, kann dieser Ordner wie `de/iphone-17-pro-max/`
befüllt werden.
