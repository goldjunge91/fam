Tagebuch

Tippe auf einen Tag · wische für ältere Tage

Karussell
Feste Breite pro Tag (34px, flex: 0 0 34px) statt flex:1 — die Reihe (14 Tage, zwei Wochen) ist bewusst breiter als die Box und scrollt seitlich. Start ist immer bei "Heute" rechts, der Tag davor wird links sichtbar angeschnitten.
Verhalten
Tap auf einen Tag lädt Bilanz, Makros und Mahlzeiten darunter neu. Ein Tag ohne Einträge zeigt einen leeren Track ohne Füllung und darunter "Keine Einträge an diesem Tag". Balken/Makro-Chips färben sich in Warnfarbe bei Zielüberschreitung.
