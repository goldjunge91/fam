# fam Premium · Native Paywall Mockups

Interaktive HTML-Mockups für die native React-Native-Paywall im warmen Fam-Design-System.

## Datei öffnen

Öffne die Datei [`custom-paywall-mockup.html`](./custom-paywall-mockup.html) direkt im Browser:

```bash
open docs/mockups/custom-paywall/custom-paywall-mockup.html
```

## Varianten im Überblick

1. **Variante 1: Card Stack (Vertikale Plan-Karten)**
   - Vertikale Plan-Karten mit Radio-Auswahl.
   - Prominentes `17% Ersparnis`-Badge auf dem Jahresabo.
   - Monatsäquivalent (`4,16 € / Monat`) klar ausgewiesen.
   - Kompakte Feature-Liste mit Icons.
   - *Empfohlen:* Höchste Klarheit und bewährte Conversion-Struktur.

2. **Variante 2: Segmented Switch**
   - Schlanker Umschalter oben (Monatlich vs. Jährlich).
   - Große dynamische Preisanzeige im Fokus.
   - Direkte Erklärung der Haushalts-Gültigkeit.

3. **Variante 3: Kachel-Vergleich (Side-by-Side)**
   - Zwei Kacheln nebeneinander zum direkten horizontalen Preisvergleich.
   - Sehr kompakt für kürzere Bildschirme.
