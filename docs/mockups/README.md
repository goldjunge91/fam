# Mockups

Statische HTML-Mockups für UI-/Layout-Änderungen, bevor an echten Komponenten gearbeitet
wird (siehe AGENTS.md, "Visual and design work"). Ein Unterordner pro Feature.

Jeder Unterordner enthält die zuletzt akzeptierte Mockup-Datei plus einen Verweis auf die
zugehörige Live-Artifact-URL, falls vorhanden.
