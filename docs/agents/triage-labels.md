# Triage Labels

Die Skills sprechen in fünf kanonischen Triage-Rollen. Diese Datei mappt diese Rollen auf die tatsächlichen Label-Strings im Issue-Tracker dieses Repos.

| Label in mattpocock/skills | Label in unserem Tracker | Bedeutung                                    |
| --------------------------- | ------------------------ | --------------------------------------------- |
| `needs-triage`               | `needs-triage`             | Maintainer muss das Issue bewerten            |
| `needs-info`                 | `needs-info`               | Wartet auf weitere Infos vom Reporter         |
| `ready-for-agent`            | `ready-for-agent`          | Vollständig spezifiziert, bereit für AFK-Agent |
| `ready-for-human`            | `ready-for-human`          | Erfordert menschliche Umsetzung               |
| `wontfix`                    | `wontfix`                  | Wird nicht umgesetzt                          |

Wenn ein Skill eine Rolle nennt (z. B. "das AFK-ready-Triage-Label setzen"), den zugehörigen Label-String aus dieser Tabelle verwenden.

Die rechte Spalte anpassen, falls im Repo abweichende Label-Namen genutzt werden.
